# littledarkage

«Короткий тёмный век» (Little Dark Age) — браузерная игра по одноимённой ролевой: крысиные солдаты, бой вслепую в паре «ударник — координатор», казарма между тревогами и философ Крыпоткин, который не верил в свои идеи.

- [docs/concept.md](docs/concept.md) — концепция веб-версии: сюжет, механики, фидбэк прогона 2022 года, правки, техплан, вехи и открытые вопросы.
- [docs/source](docs/source/) — исходные документы ролевой (`.docx` и их текст в `.md`) и [письма из дома](docs/source/letters.md).

## Запуск

Нужен Node 22.13 или новее.

```sh
npm ci
npm run dev          # игра на http://localhost:5173
npm run dev:server   # сервер на :3000 (пока только раздаёт игру)
npm test             # тесты игры и сервера
npm run build && npm start   # собранная игра на http://localhost:3000
```

`?debug` в адресе показывает ползунок «где в игре» (как рвётся плакат), `?t=0.55` открывает сцену сразу на этом месте.

Деплой: пуш в `main` → CI (типы, тесты, сборка, Docker и smoke-тест) → Amvera собирает `Dockerfile` по `amvera.yml`.
