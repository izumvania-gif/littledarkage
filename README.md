# littledarkage

«Короткий тёмный век» (Little Dark Age) — браузерная игра по одноимённой ролевой: крысиные солдаты, бой вслепую в паре «ударник — координатор», казарма между тревогами и философ Крыпоткин, который не верил в свои идеи.

- [docs/concept.md](docs/concept.md) — концепция веб-версии: сюжет, механики, правки, техплан, вехи и вопросы.
- [docs/source](docs/source/) — исходные документы ролевой (`.docx` и их текст в `.md`).
